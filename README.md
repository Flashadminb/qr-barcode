# สร้าง QR & Barcode

เว็บแอพสร้าง QR Code และบาร์โค้ด — พิมพ์หรือวางข้อความแล้วได้โค้ดทันที

**ใช้งาน:** https://flashadminb.github.io/qr-barcode/

- QR Code, Data Matrix, PDF417, Aztec และบาร์โค้ด Code 128, EAN‑13, EAN‑8, UPC‑A/E, Code 39/93, ITF‑14, ITF, Codabar, MSI, Pharmacode
- ใส่หัวข้อด้านบนและชื่อ/คำอธิบายด้านล่างรูปได้ (ติดไปกับรูปที่คัดลอก/บันทึก)
- บอกชัดๆ ว่าแต่ละแบบใช้กับอะไร
- **สร้างทีละหลายอัน**: ใส่ทีละบรรทัด (หรือแยกด้วยเว้นวรรค/จุลภาค) ใส่ชื่อแต่ละอันด้วย `รหัส | ชื่อ` หรือก๊อป 2 คอลัมน์จาก Excel แล้วบันทึกเป็น ZIP, รวมเป็นภาพเดียว หรือพิมพ์เป็นแผ่นสติกเกอร์
- คลิกที่รูปเพื่อคัดลอก หรือบันทึก PNG / SVG ในคลิกเดียว
- ดูตัวอย่างทุกแบบพร้อมกัน และแนะนำแบบที่เหมาะกับข้อความ
- ตัวช่วยกรอก: Wi‑Fi, พร้อมเพย์ (ใส่จำนวนเงินได้), โทร/SMS, อีเมล
- ปรับสี พื้นโปร่งใส ขนาด ระดับกู้คืนข้อมูล และใส่โลโก้กลาง QR
- จำประวัติไว้ในเครื่อง (ค้นหา ปักหมุด ลบได้)
- เปิดด้วยลิงก์ `?t=ข้อความ&top=หัวข้อ&bottom=ชื่อ` เพื่อสร้างโค้ดให้ทันที
- ใช้บนมือถือได้สะดวก: แถบปุ่มลัดด้านล่าง กดค้างที่รูปเพื่อบันทึก ติดตั้งเป็นแอพบนหน้าจอโฮม และใช้งานออฟไลน์ได้

ทำงานในเบราว์เซอร์ทั้งหมด ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์
